Weld UT Simulator Guide v1.0

Educational Ultrasonic Testing (UT) simulator for weld inspection · ASME Sec. V Art. 4 reference · Versi Indonesia

1. Getting started

  • Opening: open index.html in Chrome/Edge/Firefox, or the simulator’s GitHub Pages address. No installation or server is needed.
  • Offline: after being opened once over http(s), the simulator is stored on the device and keeps working offline. On phones choose Add to Home screen.
  • Language: the EN/ID button at the top right switches the whole interface, tutorials and reports.
  • Data: reports, sessions and class summaries are stored only on the user’s device (files or browser storage).

3. Inspection workflow

  1. Probe calibration (the New probe button gives a probe with hidden errors): on the IIW V1/V2 block maximise the R100 echo (V2: R25/R50) → enter the X-value; adjust zero (and velocity) until the echoes are exactly at 100/200 mm; check the angle with the Ø50 hole (V1), Ø1.5 (70°–80°) or Ø5 (V2) → enter the measured angle.
  2. DAC on the ASME basic calibration block: maximise the ¼T, ½T, ¾T SDHs, then via leg 2; record each point without changing the gain. Press Gain = reference, then Scanning gain (+6 dB). TCG is optional.
  3. Scan the weld from both sides and along its length. Set Gate A to enclose the echo.
  4. Sizing: length with 6 dB drop (peak at 80% → mark the ends at 40%), height with 6 dB drop or TOFD.
  5. Evaluation: choose ASME Sec. VIII Div. 1 App. 12 or AWS D1.1 (reference b from the Ø1.5 hole of the IIW block, face B), choose the indication interpretation.
  6. Report: + Add from current reading, fill in Report data (project, procedure, instrument, couplant, …), then print/PDF or download .html.

4. Special test pieces

  • Pipes: girth welds (clock positions) or longitudinal/seam welds (circumferential section; maximum angle given by t/D). Use a contoured wedge and a curved calibration block for small diameters.
  • Austenitic steel: high grain noise; compare shear and longitudinal waves, enable Weld metal anisotropy to see beam skewing.
  • Corroded plate: single or dual (TR) 0° probe, C-scan thickness map, click the map to move the probe.
  • Tubular T/Y/K/X joints: choose the circumferential position φ (heel 0°, toe 180°); the local section follows the dihedral angle Ψ; the info line shows the ideal probe angles; circumferential B-scan of the brace.

6. Exams & class summary

  • Levels: Easy (DAC provided), Medium (build the DAC), Hard (probe calibration + DAC), Full practical (calibration, DAC and scanning gain graded at 30%).
  • Instructor settings: exam test piece (plate, pipe girth, pipe seam, tubular), number of flaws, time limit (answers are submitted automatically when time runs out), task source (random from code or instructor scenario).
  • Exam package code (UTX1:…): the instructor presses Create exam package code and shares it; students paste it and press Use package.
  • Grading: detection 40, location 15, length 15, type 15, decision 15 per flaw; −10 per false call.
  • Class summary: import student result files (.json) or reports (.html); scores are recalculated from the task code; statistics and CSV download.

7. Instructor tools

  • Scenario editor: on the Flaws & display card choose Instructor scenario (custom), define the flaws (type, side, y position, depth, x), press Apply. Save as a file or share with a UTS1:… code.
  • Exam from a scenario: on the Exam tab choose Task source: Instructor scenario, then create an exam package code.
  • Teacher mode: tick Show flaws & true exit point (locked during exams).

8. Save & open sessions

Save session stores the settings, probe, calibration, DAC, sizing, report data and indication table in a .json file; Open session restores it. Not available while an exam is running.

9. Model & limitations

  • 2D cross-section with ray paths (reflections at flat/curved surfaces), amplitude from the coherent sum of flaw surface points, Gaussian beam profile, attenuation, beam spreading, grain noise.
  • Amplitudes are qualitative and not validated against a specific instrument. Tubular joints use a local section (no 3D beam skew). The AWS D1.1 table is compiled for education; the tubular Class R/X criteria are not included.
  • The simulator does not replace practice with real equipment and specimens; its reports are not official inspection documents.
