Panduan Simulator UT Las v1.0

Simulator edukasi Ultrasonic Testing (UT) untuk inspeksi las · acuan ASME Sec. V Art. 4 · English version

1. Memulai

  • Membuka: buka index.html di Chrome/Edge/Firefox, atau alamat GitHub Pages simulator. Tidak perlu instalasi atau server.
  • Tanpa internet: setelah sekali dibuka lewat http(s), simulator tersimpan di perangkat dan tetap berjalan offline. Di HP pilih Tambahkan ke layar utama.
  • Bahasa: tombol EN/ID di kanan atas mengganti seluruh tampilan, tutorial, dan laporan.
  • Data: laporan, sesi, dan rekap kelas hanya tersimpan di perangkat pengguna (file atau penyimpanan browser).

3. Alur kerja inspeksi

  1. Kalibrasi probe (tombol Probe baru memberi probe dengan galat tersembunyi): di blok IIW V1/V2 cari echo R100 (V2: R25/R50) maksimum → isi X-value; atur zero (dan velocity) sampai echo tepat 100/200 mm; cek sudut dengan lubang Ø50 (V1), Ø1,5 (70°–80°) atau Ø5 (V2) → isi sudut terukur.
  2. DAC di blok kalibrasi dasar ASME: maksimalkan SDH ¼T, ½T, ¾T, lalu lewat leg 2; rekam tiap titik tanpa mengubah gain. Tekan Gain = reference, lalu Gain scanning (+6 dB). TCG opsional.
  3. Scan las dari kedua sisi dan sepanjang las. Atur Gate A agar melingkupi echo.
  4. Sizing: panjang dengan 6 dB drop (puncak 80% → tandai ujung saat 40%), tinggi dengan 6 dB drop atau TOFD.
  5. Evaluasi: pilih acuan ASME Sec. VIII Div. 1 App. 12 atau AWS D1.1 (reference b dari lubang Ø1,5 blok IIW sisi B), pilih interpretasi indikasi.
  6. Laporan: + Tambah dari pembacaan saat ini, lengkapi Data laporan (proyek, prosedur, alat, couplant, …), lalu cetak/PDF atau unduh .html.

4. Benda uji khusus

  • Pipa: las girth (posisi jam) atau memanjang/seam (penampang keliling; sudut maksimum menurut t/D). Gunakan Wedge dikontur dan blok kalibrasi lengkung untuk diameter kecil.
  • Baja austenitik: noise butir tinggi; bandingkan gelombang geser dan longitudinal, aktifkan Anisotropi logam las untuk melihat pembelokan berkas.
  • Pelat korosi: probe lurus 0° tunggal atau dual (TR), C-scan peta tebal, klik peta untuk memindahkan probe.
  • Sambungan tubular T/Y/K/X: pilih posisi keliling φ (heel 0°, toe 180°); penampang lokal mengikuti sudut dihedral Ψ; baris info menunjukkan sudut probe ideal; B-scan keliling brace.

6. Ujian & rekap kelas

  • Tingkat: Mudah (DAC disediakan), Sedang (buat DAC), Sulit (kalibrasi probe + DAC), Praktik lengkap (proses kalibrasi, DAC, gain scanning ikut dinilai 30%).
  • Pengaturan instruktur: benda uji soal (pelat, pipa girth, pipa seam, tubular), jumlah cacat, batas waktu (jawaban terkirim otomatis saat waktu habis), sumber soal (acak dari kode atau skenario instruktur).
  • Kode paket ujian (UTX1:…): instruktur menekan Buat kode paket ujian dan membagikannya; siswa menempel kode lalu Pakai paket.
  • Penilaian: deteksi 40, lokasi 15, panjang 15, jenis 15, keputusan 15 per cacat; −10 per indikasi palsu.
  • Rekap kelas: impor file hasil (.json) atau laporan (.html) siswa; nilai dihitung ulang dari kode soal; statistik dan unduh CSV.

7. Alat instruktur

  • Editor skenario: pada kartu Cacat & tampilan pilih skenario Skenario instruktur (kustom), susun cacat (jenis, sisi, posisi y, kedalaman, x), tekan Terapkan. Simpan sebagai file atau bagikan lewat kode UTS1:….
  • Soal dari skenario: di tab Ujian pilih Sumber soal: Skenario instruktur, lalu buat kode paket ujian.
  • Mode guru: centang Tampilkan cacat & exit point sebenarnya (terkunci selama ujian).

8. Simpan & buka sesi

Tombol Simpan sesi menyimpan pengaturan, probe, kalibrasi, DAC, sizing, data laporan, dan tabel indikasi ke file .json; Buka sesi memulihkannya. Tidak tersedia selama ujian berjalan.

9. Model & batasan

  • Penampang 2D dengan lintasan sinar (pantulan di permukaan datar/lengkung), amplitudo dari penjumlahan koheren titik-titik permukaan cacat, profil berkas Gaussian, atenuasi, penyebaran berkas, noise butir.
  • Amplitudo bersifat kualitatif dan belum divalidasi terhadap alat tertentu. Tubular memakai penampang lokal (tanpa skew berkas 3D). Tabel AWS D1.1 disusun untuk edukasi; kriteria tubular Class R/X belum dimasukkan.
  • Simulator tidak menggantikan latihan dengan alat dan spesimen nyata; laporan yang dihasilkan bukan dokumen inspeksi resmi.
